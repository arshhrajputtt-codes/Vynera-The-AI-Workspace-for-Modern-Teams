# Nexora Identity Service

The Identity Service is the authentication and authorization service for Nexora.

## Features

- User Registration
- User Login
- JWT Authentication
- Workspace Creation
- Role-Based Access Control (Planned)

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Docker

## Run

```bash
uvicorn app.main:app --reload
```
